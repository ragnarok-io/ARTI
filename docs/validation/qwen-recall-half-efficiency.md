# Qwen Recall + Half Efficiency Baseline

This benchmark is ARTI's first reproducible adaptation-efficiency baseline. It
uses `Qwen/Qwen3-0.6B`, CUDA BF16, a fixed generated instruction dataset, 24
updates, batch size two, and independent seeds `17`, `29`, and `43`.

The primary comparison is parameter-matched LoRA versus LoRA plus one ARTI
Recall adapter with the default Half trace-survival activation. Full fine-
tuning is included as a same-task resource reference, not as a parameter-
matched baseline.

| Variant | Trainable parameters | Validation loss | Target token accuracy | Greedy exact match |
| --- | ---: | ---: | ---: | ---: |
| Full fine-tuning | 596.0M | 2.5040 +/- 1.0333 | 28.0% | 9.4% |
| LoRA | 24.77M | 0.6372 +/- 0.3017 | 85.3% | 54.2% |
| LoRA + Recall + Half | 26.21M | 0.3382 +/- 0.1535 | 90.7% | 72.9% |
| LoRA + Recall, no Half | 26.21M | 0.3305 +/- 0.1515 | 88.7% | 76.0% |
| LoRA + Recall + Half, depth 2 | 26.21M | 0.3302 +/- 0.1526 | 90.7% | 76.0% |
| LoRA + Recall + Half, layer 8 | 26.21M | 0.3016 +/- 0.1042 | 90.0% | 75.0% |

The matched LoRA budget differs by 5.47%, the closest available discrete LoRA
rank. Recall + Half improved validation loss on all three shared seeds and
met the pre-registered recommendation rule: at least 1% mean loss improvement,
positive improvement in at least two thirds of seeds, no greedy exact-match
regression, and at most 10% parameter mismatch.

The Half ablation is deliberately interpreted more narrowly. On this short,
clean task, Recall without Half and depth-two Recall are comparable to the
default. The layer-8 insertion is better than the layer-1 default under the
same budget, so injection location is a material hyperparameter. Neither fact
justifies a universal claim about Half or a universal preferred layer; the
next benchmark should search placement on noisier and longer-context tasks.

Reproduce the complete result:

```bash
uv run --extra qwen --extra peft python benchmarks/run_qwen_recall_half_efficiency.py \
  --steps 24 --batch-size 2 --seeds 17,29,43 --include-full-finetune \
  --output benchmarks/results/qwen_recall_half_efficiency.json
uv run --extra qwen --extra peft python benchmarks/verify_qwen_recall_half_efficiency.py
```

The result JSON embeds the exact dataset records and SHA-256, model revision,
dependency versions, loss curves, per-run resource measurements, and the
recommendation calculation. A seed-17 trainable adapter checkpoint is stored
locally under `benchmarks/artifacts/` with SHA-256
`78c95b975c31198d432550533535eda0197e1dc78fd35ea931bb905fa0bf56d2`; checkpoints
are intentionally Git-ignored and regenerated by passing `--save-adapters`.
