# ARTI

ARTI = AI x RT.

ARTI is a PyTorch-first latent tensor dynamics package for neural networks that need structured runtime representation updates. It provides tensor-in / tensor-out layers with coordinates, masks, visibility constraints, virtual interfaces, virtual recall alignment, diagnostics, and GPU-ready validation paths.

ARTI is domain-free. Downstream systems encode context into tensors, coordinates, masks, visibility, and optional frame operators; ARTI transforms anonymous latent tensors.

The current stable surface also includes standalone activation/workspace APIs
(`Half`, `Fold`, `Pulse`, `RecallExecutor`), glyph-first text tensors, runtime
vocabulary binding, participant/membrane context helpers, and controlled Qwen
adapter probes.

## Current Focus

ARTI is being developed as an industrial package with:

- PyTorch-first implementation
- explicit `arti.torch` backend namespace
- GPU-ready tests and benchmarks
- autogenerated API documentation
- mechanism-level validation artifacts
- an optional JAX functional backend boundary

## Install

```bash
uv sync --extra torch --extra dev
```

For documentation:

```bash
uv sync --extra torch --extra docs --extra dev
uv run mkdocs serve
```

## Minimal Example

```python
import torch
from arti import ARTILayer

layer = ARTILayer()

x = torch.randn(4, 16, 32)
assert torch.equal(layer(x), x)
```

`ARTILayer@3` is an identity host until it is supplied with a configured
FederatedProgram or ProgramGraph. See [Shape-Autonomous Bank Contracts](guides/federal-contracts.md)
for an executable Program region. The earlier parameterized latent-tensor layer
is available only as `arti.legacy.ARTILayer`.

## Design Boundary

ARTI is not a business model, prediction system, data framework, or task-specific model. It is a reusable latent tensor dynamics layer that can be inserted into larger models.
