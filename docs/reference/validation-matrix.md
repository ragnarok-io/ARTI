# Validation Matrix

This page maps ARTI mechanisms to the smallest useful verification
commands and the claims they are allowed to support. It is intentionally
conservative: a green check here means a mechanism invariant is protected, not
that ARTI has won a broad downstream benchmark.

## Developer Gates

| Gate | Command | Proves | Does Not Prove |
| --- | --- | --- | --- |
| First run | `uv run --extra torch python examples/pytorch_dependency_quickstart.py` | The public PyTorch API imports and runs a basic forward pass. | Mechanism correctness or package release readiness. |
| Quick | `uv run --extra dev python scripts/quality_gate.py quick` | Core tests, masks, serialization, generated docs, backend reports, and smoke validation pass locally. | Full mechanism evidence or Qwen integration. |
| Mainline | `uv run --extra dev python scripts/quality_gate.py mainline` | Compact verifier-only release path: direct Qwen hidden Half control, `verify_core_goal.py` for the Qwen string/glyph dynamic-vocab and latent-repair goal chains, and evidence-schema checks. | Does not regenerate heavyweight training evidence. |
| Docs | `uv run --extra docs python scripts/quality_gate.py docs` | Generated docs are current and MkDocs builds strictly. | Runtime behavior. |
| Package | `uv run --extra dev python scripts/quality_gate.py package` | Wheel/sdist build and installed-package imports work. | CUDA, Qwen, or mechanism superiority. |
| Qwen | `uv run --extra dev python scripts/quality_gate.py qwen` | Qwen-shaped, frozen-forward where available, public Qwen adapter API, input/output-head replacement, short-context closed loop, short autoregressive writeback, controlled open-generation writeback, external glyph answering, multi-token glyph decoding, runtime-vocab, pulse, OOV dialogue-preservation, and membrane adapter gates pass. Live string-first answer probes are separate heavyweight checks. | Full Qwen tokenizer replacement or base-model fine-tuning gains. |

## Mechanism Gates

| Mechanism | Primary Commands | Positive Claim | Negative Controls / Boundaries |
| --- | --- | --- | --- |
| Coordinates / phase | `research-only validation entrypoint`; `research-only validation entrypoint` | Authority identity can be represented by phase tensors when text content is symmetric. | Not a production prompt-injection guarantee; visibility is tested separately. |
| Autoregressive observer phase | `research-only validation entrypoint` | A next-token observer phase can be applied as the reference frame for context inversion. | Does not prove open-ended LLM role behavior. |
| Mask / visibility | `scripts/validate_arti.py`; `research-only validation entrypoint` | Invalid or invisible tokens do not contribute to the tested updates. | Does not define business authorization by itself. |
| Virtual interface | `research-only validation entrypoint`; `research-only validation entrypoint` | Fixed-size interfaces can preserve source-separable multi-source information under controlled readout. | Not a full long-context throughput benchmark. |
| Virtual recall | `research-only validation entrypoint`; `research-only validation entrypoint` | Recall capacity can reconstruct internal processing traces under controlled corruption. | Recall stores processing memory, not external facts or answers. |
| Half recall trace survival | `research-only validation entrypoint`; `research-only validation entrypoint` | `Half` can thin candidate Recall deltas by retaining strong signed traces while reducing weak-trace leakage and stacked-depth pollution; matched fixed-shrink controls check that this is not merely global delta shrinkage. | Half remains a generic stateless activation; SoftShrink-style controls can be lower-noise at the cost of attenuating signed traces, so this is not broad denoising dominance or a stateful memory mechanism. |
| Half recall fair training | `research-only validation entrypoint`; `research-only validation entrypoint` | Under equal trainable parameters, train/eval batches, weak-trace streams, and direct `mse(state, h + r_true)` loss, `Half` improves trained Recall-delta target MSE versus identity/fixed-shrink controls while preserving strong signed traces. | Synthetic salience-separable hidden-state reconstruction only; records SoftShrink's lower-noise tradeoff rather than claiming scalar dominance. |
| RecallRefiner | `research-only validation entrypoint`; `research-only validation entrypoint` | Iterative Recall plus default Half can refine masked/noisy hidden vectors over multiple steps while reducing weak correction drift versus the no-Half loop under equal training examples and near-equal trainable parameter budgets. | Synthetic hidden-vector task only; not broad denoising, downstream superiority, or a replacement for the existing recall path. |
| Layered Recall trajectory | `research-only validation entrypoint`; `research-only validation entrypoint` | Three layer-bound Recall branches beat every parameter-matched single-layer location in every seed on single and combined corruptions; monotonic depth curves and layer-order/artifact controls support depth-specific trace composition with low unseen influence. | Frozen synthetic Transformer-like backbone; matched adapters have lower direct MSE but substantially higher unseen influence, so this is not broad superiority over adapters/LoRA or full-Qwen evidence. |
| Pulse refiner repair | `research-only validation entrypoint`; `research-only validation entrypoint` | Same-parameter paired Fold/Pulse plus RecallRefiner variants show Pulse + Half preserving ordered strong traces while reducing weak-trace leakage and weak-noise gain, with non-increasing per-step repair curves and every recorded refinement step no worse than the no-Half Fold path. The gate also checks explicit input pressure, a clean ordered workspace training-objective contract, final weighted loss components, Pulse update-norm contraction across refinement depth, recomputed throughput bounds, and CUDA peak memory. | Synthetic overcomplete-fragment repair only; not broad downstream superiority or a Qwen result. |
| Pulse refiner multi-seed | `research-only validation entrypoint`; `research-only validation entrypoint` | Across three paired seeds, Pulse + Half improves signal-only incomplete-state recovery and lowers weak-trace leakage and weak-noise gain in every seed under equal parameters and budgets. | Corrupted-input final MSE is not dominant: the evidence records a bounded 1-4% tradeoff instead of promoting the favorable single seed into a broad claim. |
| Latent repair goal | `research-only validation entrypoint` | Aggregates Half trace survival, Half fair training, direct RecallRefiner hidden-state repair, single-seed depth diagnostics, and paired multi-seed Pulse/Fold stability. The goal requires same-parameter evidence, direct hidden-state MSE/drift improvement, repeatable incomplete-state and anti-pollution gains, and an explicit final-MSE non-dominance boundary. | Goal-level synthetic mechanism evidence only; it does not prove broad denoising, production memory, or downstream model superiority. |
| Qwen hidden Half probe | `research-only validation entrypoint`; `research-only validation entrypoint` | On frozen Qwen-derived hidden states, paired RecallRefiner variants with equal parameters and shared seeds show Half preserving strong repair while reducing clean-start drift and weak-trace leakage. The gate also checks the recorded hidden-repair training objective, final-loss formula, and throughput formula. | Controlled hidden-repair probe only; not string generation, Qwen fine-tuning, or broad Half superiority. |
| Fold compaction | `research-only validation entrypoint`; `research-only validation entrypoint` | `Fold` can compact role-bound sparse latent traces into a fixed-size workspace, preserving ordered trace binding where q-guided mean pooling collapses the pair. | Synthetic trace-compaction task only; not broad downstream superiority. |
| Formula ProgramQuery Transformer composition | `research-only validation entrypoint`; `research-only validation entrypoint` | A bounded hard ProgramQuery can select individual Formula atoms, SSA wiring, residual/replace branches, activation, and stop from final task loss, recovering a fixed tiny Attention+MLP program across three seeds and unseen sequence lengths. Equivalent SSA execution orders are merged exactly, and the selected structure has PyTorch parity, finite gradients, reload, and a compiled CUDA Formula replay. | Fixed Bank operands and a small preregistered synthetic catalog; not unrestricted architecture search, language-model quality, learned Transformer weights, or a speed claim. |
| Pulse | `research-only validation entrypoint`; `research-only validation entrypoint` | `Pulse` can use Half+Fold to form compact learned pulse workspaces that preserve role-bound signal better than pooling and legacy explicit pulse compression on unordered noisy slots; optional sparse, q-pruned, attention, and gated-correction variants are recorded as experimental rows. | Synthetic task only; `LearnedPulse` is an alias, and this does not prove tokenizer-free modeling, compression superiority, or that every experimental efficiency knob should become default. |
| Runtime vocab | `research-only validation entrypoint`; `research-only validation entrypoint`; `research-only validation entrypoint` | The output softmax can bind to the current rigid vocab tensor and current slot order. | Not full vocabulary surgery for a pretrained LLM without adaptation. |
| Text tensor / bitmap vocab | `research-only validation entrypoint`; `research-only validation entrypoint`; `research-only validation entrypoint` | Visible text identity can be supplied as rigid glyph tensors and checked for micro-character collisions, entropy, runtime slot binding, and pulse distinctness. | Natural visible characters should be glyph-first; codepoint channels are only auxiliary for controls/fallback/confusables. |
| Legacy explicit pulse | `research-only validation entrypoint`; `research-only validation entrypoint` | Different token segmentations can map into stable externally supplied pulse slots without collapsing tested symbol differences. | Legacy explicit pulse cannot recover information already destroyed by compression and is not the default learned `Pulse` layer. |
| VisualScan | `research-only validation entrypoint`; `research-only validation entrypoint` | Under the recorded `D H T_delta` acquisition model, complementary registered subpixel observations can be compacted into a fixed Pulse workspace and recover micro-glyph identity; deterministic inverse registration generalizes to held-out continuous shifts, and shift-and-add confirms that the information exists before learning. | Repeated/no-concat controls remove the gain, wrong registration damages it, and held-out font classification does not imply faithful reconstruction of unseen font style. |
| Membrane routing | `research-only validation entrypoint`; `research-only validation entrypoint` | Inner speech is a normal token stream with restricted visibility and no user emission. | It does not prove an LLM has learned when to use inner speech. |
| Source integrity carrier | `research-only validation entrypoint`; `research-only validation entrypoint` | Synchronized multi-source payloads remain separable after superposition into field tokens. | Carrier validation is not the same as end-to-end perception quality. |

## Qwen Stages

| Stage | Command | Meaning | Boundary |
| --- | --- | --- | --- |
| Qwen-shaped smoke | `research-only validation entrypoint` | Exercises ARTI adapter paths with Qwen-class shapes and records checkpoint targets. | Offline by default; no model download unless `--run-model` is used. |
| Qwen glyph adapter API | `research-only validation entrypoint` | Loads `QwenGlyphRuntimeAdapter`, exercises frozen `generate`, glyph runtime-vocab readout, and dialogue drift checks. | Alpha adapter smoke only; not trained tokenizer replacement. |
| Runtime vocab training | `research-only validation entrypoint` | Freezes Qwen-shaped or Qwen-derived context and trains small runtime-vocab heads. | Adapter-level training only. |
| Output-head replacement | `research-only validation entrypoint` | Trains an ARTI runtime vocab output head to imitate frozen Qwen lm_head teacher distributions on dynamic candidate vocab views. | Student output-head replacement only; input embedding and open-ended intelligence are not replaced. |
| Input-head replacement | `research-only validation entrypoint` | Trains an ARTI glyph/text tensor encoder to imitate frozen Qwen token embeddings and checks frozen-body hidden/logit agreement. | Short-prompt first-stage input replacement only; not full tokenizer replacement. |
| Closed-loop replacement | `research-only validation entrypoint` | Combines ARTI glyph input encoder and runtime vocab output head around a frozen Qwen body on short contexts. | Short-context candidate-softmax smoke only; not long-context generation. |
| Autoregressive closed loop | `research-only validation entrypoint` | Rolls out 2-4 short generation steps by mapping ARTI local runtime-vocab slots back into visible token tensors for the next step. | Short-sequence greedy-teacher smoke only; not full open-ended generation. |
| Controlled open generation | `research-only validation entrypoint` | Rolls out 8-16 teacher-greedy steps with mixed runtime vocab views: teacher top-k, external visible text, OOV-like strings, permuted slots, and distractors. | Controlled adapter evidence only; generated text can still be rough and does not prove full open-ended Qwen quality. |
| Runtime vocab + pulse semantic | `research-only validation entrypoint` | Frozen Qwen contexts plus trained adapters answer deterministic semantic questions through current glyph runtime vocab slots under shuffled candidates and held-out views, compared with tokenizer-only, fixed-head, runtime-only, and pulse-only controls while recording effective batch, AMP, peak memory, samples/s, and ordinary Qwen repeated-logit drift. | Adapter-level training loop only; not full tokenizer replacement or open-ended dialogue quality; in glyph mode pulse is checked for compatibility rather than forced improvement over runtime-vocab-only. |
| Qwen learned Pulse adapter | `research-only validation entrypoint`; `research-only validation entrypoint` | Frozen Qwen contexts can use the default learned `Pulse` as a candidate-fragment compactor; optimized Pulse is compared with a previous-reference Pulse path, legacy explicit pulse, sparse/q-pruned/attention folds, and gated residual correction for accuracy, throughput, and peak memory. | Adapter-level probe only; not full Qwen fine-tuning, open-ended generation, or a claim that learned Pulse should replace every legacy explicit pulse use. |
| Qwen hidden Half refiner | `research-only validation entrypoint`; `research-only validation entrypoint` | Frozen Qwen hidden states are repaired under controlled corruption with paired no-Half/Half RecallRefiners sharing architecture, seeds, train batches, parameters, and weak-trace noise. The verifier requires the loss to be clean-hidden repair plus clean-start stability, not generated-string supervision. | Hidden-repair mechanism evidence only; not generated-string quality or Qwen fine-tuning. |
| Qwen string-first answer probe | `research-only validation entrypoint`; `research-only validation entrypoint` | Chat strings are rendered into ARTI text tensors and small ARTI-side frontends drive a frozen Qwen output/decode boundary. The training contract uses prompt-balanced prefix sampling, canonical next-token CE, a diagnostic condition-head CE, and direct first-answer-token CE through the frozen lm head. The verifier recomputes all three loss terms, checks exact canonical strings, coherence, paired budgets, matched parameters, throughput, and CUDA peak memory. | Heavyweight four-prompt probe; not full Qwen fine-tuning, tokenizer replacement, broad answer-quality evidence, or a Half mechanism verdict. |
| Qwen string Pulse multi-seed | `research-only validation entrypoint`; `research-only validation entrypoint` | Across seeds 71, 79, and 87, prompt-balanced training plus direct frozen-lm-head answer-identity loss lets Pulse reproduce all four canonical answers in every seed while the parameter-matched mean_wide baseline never reaches 4/4. Pulse also wins conditional NLL in every seed and records zero mode collapse. | Four controlled prompts at a frozen Qwen boundary; not broad language evaluation or full tokenizer replacement. |
| Strict unseen-surface probe | `research-only validation entrypoint --strict-heldout-surfaces --output benchmarks/results/qwen_runtime_vocab_pulse_strict_surface_probe.json` | Exposes whether the current adapter can answer with a positive external glyph surface never used as a positive answer during training. | Current result is intentionally a gap signal, not a release gate; it does not yet prove unseen external word semantics. |
| Strict metadata bridge probe | `research-only validation entrypoint --strict-heldout-surfaces --semantic-bridge --semantic-bridge-source metadata --vocab-glyph-scale 0.02 --output benchmarks/results/qwen_runtime_vocab_pulse_metadata_bridge_probe.json`; `research-only validation entrypoint`; `research-only validation entrypoint` | Shows that Qwen frozen-context adapters can solve held-out external vocab surfaces when runtime vocab items carry stable semantic metadata plus a nonzero glyph identity channel, and that the same strict glyph-only probe remains low. | Metadata bridge evidence is not glyph-only word understanding; raw unseen glyph semantics still require pretraining or a stronger text-vision bridge. |
| Dynamic vocab goal evidence | `research-only validation entrypoint`; `docs/validation/qwen-dynamic-vocab-goal.md` | Aggregates input-head, closed-loop, runtime+pulse, metadata bridge, bridge ablation, dialogue-preservation, and string-first answer evidence for the Qwen external-vocab alpha claim. | Still adapter-level frozen-Qwen evidence, not full tokenizer replacement or base-model vocabulary surgery. |
| OOV text vocab finetune | `research-only validation entrypoint` | Frozen Qwen context plus ARTI-side glyph runtime head can select held-out visible words from external bitmap vocab. | Qwen base weights are frozen; not full tokenizer replacement or open-ended text understanding. |
| External glyph answering | `research-only validation entrypoint` | Trains ARTI to answer short tasks from an external visible glyph vocab, bind the current slot, and write selected glyph tokens back through a 4-12 step template. | Only single-token-writeback answers are evaluated; multi-token external glyph answers need a later decoder. |
| Multi-token glyph decoder | `research-only validation entrypoint` | Selects an external glyph answer slot, decodes OOV-like answers into multiple Qwen token pieces, and writes them back step by step. | Controlled short-answer decoder only; not full tokenizer replacement or open-ended decoding. |
| OOV dialogue preservation | `research-only validation entrypoint` | An ARTI-side OOV glyph head can train while ordinary Qwen dialogue logits remain unchanged on held-out prompts. | This preserves a frozen dialogue route; it is not evidence that full Qwen weight updates preserve dialogue. |
| Membrane routing training | `research-only validation entrypoint` | Small heads learn public/inner routing on a controlled two-step task. | Simulated hidden states; not real Qwen forward. |
| Membrane guessing game simulated | `research-only validation entrypoint` | Readable dialogue trace tests non-addressable inner state, legal public hints, and refusal to reveal hidden target/scratchpad. | Simulated Qwen-shaped hidden states only. |
| Membrane guessing game real-forward | `research-only validation entrypoint` | Loads real Qwen when available, extracts frozen hidden states, and trains only adapter/router/heads. | If skipped, the result must say why; if completed, it is still frozen-forward adapter evidence. |

## CUDA And Resource Claims

Run CUDA-specific gates only when a CUDA-enabled PyTorch runtime is installed:

```bash
uv run --extra dev python scripts/quality_gate.py cuda
```

Low GPU utilization during tiny smoke runs is expected. These checks are built
for correctness and boundary evidence, not throughput saturation. CUDA scaling
claims require `cuda_scaling_profile.json` and `cuda_evidence_packet.json`
generated on the target hardware.
